# AI Engineer take-home assessment

Build an AI assistant that helps an ocean transportation operations analyst consult public guidance on cargo hold preparation and cleaning.

Feel free to create it in this cloned folder.

Follow the guided instructions below:
- **Task and submission instructions:** [INSTRUCTIONS.md](INSTRUCTIONS.md).
- **Completion checklist:** [ACCEPTANCE_CRITERIA.md](ACCEPTANCE_CRITERIA.md).
- **Data:** select short excerpts from 1–2 public documents; one publisher is enough.
- **Application:** a local web frontend connected to a local backend API; a CLI-only or API-only submission is insufficient.
- **Model access:** the backend calls a remote LLM API using a temporary, budget-limited key supplied by the team. Optional remote embeddings use the same provider and key. All other application components run locally.
- **Optional source guidance:** [PUBLIC_SOURCES.md](PUBLIC_SOURCES.md), with checked access, relevant sections and reuse limitations.
- **Checks and notes:** two executed cases, plus brief decision notes and three prioritised next steps in the README.
- **Time:** aim for 3–4 hours; stop at 5 hours, including checks, documentation and interview preparation.
- **Review:** a separate 60-minute session with a 10-minute walkthrough and no required live coding.

The prototype is a basis for a technical discussion review afterwards. Technical defence and prioritised next steps carry **65%** of the assessment; the prototype carries 20% and verification 15%. 

# Important note

We value understanding and judgement more than software sophistication. Choose your technology within the task's execution constraints. 
AI assistants are allowed without restriction.
